# Online Food Ordering System - Frontend

React + TypeScript frontend coursework project.

## Run
```bash
npm install
cp .env.example .env
npm run dev
```

## Demo login
Use any email/password on Sign In page for mock mode.

## Features
- Sign In / Sign Up UI
- JWT-style auth storage
- React Router navigation
- Food browse + search/filter
- Cart add/update/remove
- Checkout + order placement
- Order tracking
- Admin category UI
- Axios service structure
